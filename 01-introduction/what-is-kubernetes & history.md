**Kubernetes (K8s)** is an open-source **container orchestration platform** used to automate the **deployment, scaling, and management of containerized applications**.

It helps manage containers (like Docker containers) across multiple machines in a **cluster environment**.

Kubernetes was originally developed by **Google** and is now maintained by the **Cloud Native Computing Foundation (CNCF)**.

## Key Features

- **Container Orchestration** – manages multiple containers automatically
- **Auto Scaling** – increases or decreases containers based on traffic
- **Self Healing** – restarts failed containers automatically
- **Load Balancing** – distributes traffic between containers
- **Rolling Updates** – update applications without downtime
- **Service Discovery** – containers can communicate easily

## Basic Components

**Cluster**
- A group of machines running Kubernetes.

**Node**
- A machine (VM or physical) inside the cluster.

**Pod**
- The smallest deployable unit in Kubernetes.

**Container**
- The application running inside the pod.

## History of Kubernetes.

The idea behind Kubernetes comes from **Google’s internal container management system called Borg**.

## Timeline

### 2003 — Google Borg

Google created **Borg**, a cluster management system used to run large-scale applications like:

- Gmail
- Google Search
- YouTube

### 2013 — Omega

Google improved Borg and created another system called **Omega**.

### 2014 — Kubernetes Released

Google released **Kubernetes as an open-source project**.

The name **Kubernetes** comes from a **Greek word meaning “helmsman” or “ship pilot.”**

### 2015 — CNCF Adoption

Kubernetes was donated to the **Cloud Native Computing Foundation (CNCF)**.

### Today

Kubernetes is the **most popular container orchestration platform in the world**.
