**kubeadm** is a tool used to **create production-grade Kubernetes clusters**.

It helps initialize:

- Control Plane
- Worker Nodes

Unlike Minikube or KIND, kubeadm is used in **real DevOps environments**.

## Cluster Setup Steps

### 1. Install Required Tools

Install:

- kubeadm
- kubelet
- kubectl
- container runtime (Docker / containerd)

Example:
```php
sudo apt install kubeadm kubelet kubectl
```

### 2. Initialize Control Plane
```php
sudo kubeadm init
```

This command:
- Creates the control plane
- Generates cluster configuration
- Provides worker join command

### 3. Configure kubectl
```php
mkdir -p $HOME/.kube
sudo cp -i /etc/kubernetes/admin.conf $HOME/.kube/config
```

### 4. Add Worker Nodes

Use the join command generated by kubeadm:
```php
kubeadm join <control-plane-ip>:6443 --token <token>
```
